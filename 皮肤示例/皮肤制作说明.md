# 百宝匣皮肤制作说明

## 怎么装皮肤

把 `.bbskin` 文件直接拖进百宝匣窗口，装好就会自动换上。在 设置 → 皮肤 里可以随时切换或删掉。

换了皮肤以后界面乱了、找不到按钮？按 `Ctrl + Alt + 0` 马上换回原皮。也可以打开 `http://127.0.0.1:3456/?skin=off`，临时用原皮打开。

这个文件夹里的 `护眼.bbskin` 就是一个示例，拖进去试试看。

## 皮肤文件里有什么

`.bbskin` 其实就是一个 zip 压缩包，改了后缀名。里面放：

| 文件 | 必须 | 作用 |
| --- | --- | --- |
| skin.json | 是 | 名字、作者、版本等 |
| skin.css | 是 | 样式 |
| preview.png | 否 | 设置里显示的预览图（建议 400×240） |
| fonts/、images/ | 否 | 皮肤自己带的字体、图片，在 CSS 里用 `url(./fonts/xxx.woff2)` 引用 |

skin.json 的例子：

```json
{
  "名字": "护眼",
  "作者": "你的名字",
  "版本": "1.0",
  "适配": "0.8",
  "说明": "一句话介绍",
  "色板": ["#e3eddc", "#6b4f35", "#c79b4b", "#f3f6ec"]
}
```

- 色板：没有 preview.png 时，用这 4 个颜色画一张小预览：底色、顶栏和边框、小圆点、卡片。
- 适配：做皮肤时百宝匣的版本。百宝匣更新以后，设置里会提示"新加的部分界面可能还是原皮的样子"。

## 怎么写 skin.css

最简单的做法是只改颜色变量（看 `护眼.bbskin` 里的 skin.css）：

```css
body {
  --page: #e3eddc;   /* 页面底色 */
  --surface: #f3f6ec;/* 卡片、面板 */
  --frame: #6b4f35;  /* 柜子、主要按钮 */
  --ink: #2f3a2c;    /* 文字 */
  --muted: #6c7a66;  /* 次要文字 */
  --line: #c9d4bf;   /* 分隔线 */
  --brass: #c79b4b;  /* 强调色 */
}
```

想改得更彻底，可以直接改各个部件的样式。常用的部件：

- `.bar` 顶栏
- `.cabinet` 柜子
- `.drawer` 抽屉（工具），里面有 `.glyph` 图标、`.slip` 名字、`.status-text` 状态
- `.sect-bar` 栏目
- `.reader` 记忆区的文章
- `.md .quick` 速查卡
- `.panel` 右边弹出的面板
- `.btn` 按钮

工具的状态在 `.drawer[data-state="running"]` 上，可能的值有 running、busy、error。

工具用得多不多在 `.drawer[data-heat="0"]` ～ `data-heat="5"` 上，5 是最常用的。自带的星空皮肤用它让常用的工具更亮。

几个常用的写法：

- 只在某个区出现的东西：用 `body:has(#view-tools:not([hidden]))`。自带的动漫皮肤就是这样放看板娘的。
- 想看完整的写法：可以参考百宝匣文件夹里的 `public/skins/minimal/skin.css`（极简）和 `public/skins/anime/skin.css`（动漫）。

## 带一个看板娘

皮肤可以带一套立绘，百宝匣会让她站在工具区右下角：会呼吸、会眨眼，跟着"问问"的回答换动作，点她就能聊天，很久不操作会犯困。打开"问问"时，她会站到面板旁边。

1. 准备几张立绘，最好是透明背景的 PNG 或 WebP，**每张的大小、人物位置都一样**，只是动作和表情不同。建议竖版 2:3，宽 600 像素左右就够了
2. 放进皮肤文件夹，比如 `chara/` 里
3. 在 skin.json 里加上"看板娘"这一段，写清楚每个动作用哪张图：

```json
"看板娘": {
  "名字": "小星",
  "图片": {
    "待机": "chara/待机.webp",
    "待机-闭眼": "chara/待机-闭眼.webp",
    "思考": "chara/思考.webp",
    "说话": "chara/说话.webp",
    "找到了": "chara/找到了.webp",
    "开心": "chara/开心.webp",
    "惊讶": "chara/惊讶.webp",
    "困": "chara/困.webp",
    "玩游戏": "chara/玩游戏.webp"
  }
}
```

- 只有"待机"是必须的，其他缺了会自动用相近的代替（比如没有"找到了"就用"开心"，再没有就用"待机"）
- "待机-闭眼"要和"待机"除了眼睛以外一模一样，百宝匣用它来眨眼
- 很久不操作会先换成"困"，再久一点换成"玩游戏"
- 皮肤 CSS 里可以用 `#mascot`（整个看板娘）、`#mascot .mc-bubble`（她头上的对话框）、`#mascot[data-mood="思考"]`（某个动作时）来改样子
- 窗口宽度小于 1100 像素时不显示，免得挡住东西；设置 → 皮肤 里可以关掉

### 用 Live2D 模型当看板娘

看板娘也可以是一个 Live2D 模型（Cubism 3 / 4 / 5 导出的 `.model3.json`）：会呼吸、眨眼，头和眼睛跟着鼠标转，跟着"问问"的回答换表情、做动作，说话时会动嘴。

1. 把模型的运行时文件整个放进皮肤文件夹，比如 `live2d/`：`.model3.json`、`.moc3`、贴图文件夹、`.physics3.json`、`.motion3.json`、`.exp3.json`、`.cdi3.json`。编辑器的工程文件（`.cmo3`、`.can3`）不用放
2. 在"看板娘"里加上 `live2d`，再按需要给每种心情配表情、动作或者参数：

```json
"看板娘": {
  "名字": "小星",
  "live2d": "live2d/xiaoxing.model3.json",
  "缩放": 1,
  "左右": 0,
  "上下": 0,
  "心情": {
    "找到了": { "表情": "微笑", "动作": "Nod" },
    "开心": { "表情": "微笑" },
    "惊讶": { "表情": "惊讶" },
    "思考": { "参数": { "ParamAngleZ": 8, "ParamEyeBallY": 0.6 } },
    "困": { "参数": { "ParamEyeLOpen": 0.3, "ParamEyeROpen": 0.3, "ParamAngleY": -10 } },
    "玩游戏": { "参数": { "ParamAngleY": -16 } }
  },
  "图片": { "待机": "chara/待机.webp" }
}
```

- "表情"写模型 `.model3.json` 里 Expressions 的 Name；"动作"写 Motions 里的组名（比如 Idle、Nod）；"参数"是要叠上去的姿势，写参数 ID 和数值，换心情时会慢慢过渡
- 没配的心情会自己猜：表情里有"微笑 / smile"就拿来当开心，有"惊讶 / surprised"就拿来当惊讶
- 说话时自动动嘴，用的是 ParamMouthOpenY；模型的张嘴参数叫别的名字的话，加一行 `"张嘴参数": "参数ID"`
- 缩放、左右、上下用来调模型在框里的大小和位置（左右、上下是 -1 到 1，按框的宽高算）
- 同时写了"图片"的话，Live2D 加载不出来时会用立绘代替
- 调心情时，按 F12 打开开发者工具，输入 `baibaoMascot('开心')` 就能马上看到效果
- Live2D 要用到 Live2D 公司的运行库 Cubism Core，它不能随百宝匣一起分发，所以第一次显示 Live2D 看板娘时，百宝匣会从 Live2D 官网下载一份存在本机（文件夹里的 `.live2d`）。连不上官网的话，在"联网代理"里填代理，或者自己下载 `live2dcubismcore.min.js` 放进百宝匣文件夹
- Live2D 模型有自己的使用许可，别人做的模型放进皮肤分享之前，先确认作者允许

## 安全规则

皮肤只能改样子，不能带程序：

- 只收 css、json、图片（png/jpg/gif/webp/svg）、字体（woff/woff2/ttf/otf）、Live2D 模型（moc3）、txt、md 这几种文件，其他的会被丢掉。
- CSS 里的 `@import` 和外部网址（http://…）会被去掉，皮肤只能用自己带的文件。
- 压缩包不能超过 30MB。
