# 百宝匣使用说明
标签: 百宝匣, 加工具, 怎么用

## 速查
- 打开：桌面版双击"百宝匣.exe"；网页版双击"启动百宝匣.bat"，浏览器会自动打开页面
- 加工具：工具区最后一格"加一个工具"，填表点"放进柜子"；改工具、拿掉工具：点抽屉右上角的 ⋯
- 栏目：工具区左上角"新建栏目"，按住抽屉拖到栏目上就放进去
- 写说明：记忆区"新建说明"，截图直接 Ctrl+V 粘贴进去
- 收资料：PDF、电子书、Word / Excel / PPT 直接拖进窗口，在百宝匣里就能看，里面的字也能搜到
- PDF 转成说明：资料里 PDF 那一行点"转成说明"，文字和图片变成一篇能直接修改的说明
- 搜索：按 `/` 打字，回车直接打开第一个结果
- 活页：记忆区最上面那排彩色标签，把说明、资料拖到标签上就分好类；Alt+1～9 直接打开第几张
- 问问：右上角"问问"，AI 管家会翻你的资料回答，还能听吩咐打开工具、新建说明（先在设置里填 AI）
- 随身口袋：右上角"口袋"，文件拖进去、拖出来；连上末影箱后，在学校、公司的电脑上也能拿到
- 换皮肤：右上角齿轮 → 皮肤；界面乱了按 Ctrl+Alt+0 换回原皮
- 更新：把 .bbupdate 小更新包拖进窗口，数据不会动
- 设置、备份、关闭、开机自启：右上角齿轮

## 详细

### 一、开始使用

#### 下载和安装

到 GitHub 的 Releases 页面（https://github.com/mengyiheqiao/baibaoxia/releases/latest ）下载：

| 文件 | 适合谁 |
| --- | --- |
| Baibaoxia-Desktop-x.x.x.zip | 桌面版，大多数人选这个。Windows 10 / 11，解压后双击"百宝匣.exe" |
| Baibaoxia-Web-x.x.x.zip | 网页版，要先装 Node.js（20 或更新），也能在 macOS / Linux 上用 |
| Baibaoxia-Update-x.x.x.bbupdate | 小更新包，已经在用百宝匣的人拖进窗口就能升级 |
| Baibaoxia-Box-Web.html | 末影箱网页版，没装百宝匣的电脑用浏览器打开 |

桌面版：

1. 解压到一个常用的地方，比如 `D:\百宝匣`。不要放在 `C:\Program Files` 里，否则没法保存数据和更新
2. 双击"百宝匣.exe"。Windows 提示"已保护你的电脑"时，点"更多信息"→"仍要运行"（因为软件没有付费签名）
3. 第一次打开会问"这是你自己的电脑吗？"：自己的电脑选"我自己的电脑"；学校、网吧这种别人的电脑选"临时用一下"（见"五、随身口袋和末影箱"）
4. 以前用过网页版的，还会问要不要把那边的数据搬过来

网页版：双击"启动百宝匣.bat"（macOS / Linux 在文件夹里运行 `node server.js`），浏览器会打开 http://127.0.0.1:3456 。用的时候黑色窗口别关，关掉百宝匣就停了，由它开的工具（比如本地跑的小网站）也会一起关掉。

#### 界面

- 顶上：搜索框、"工具区 / 记忆区"两个页签、口袋、问问、齿轮（设置）
- 工具区：一个柜子，每个工具是一格抽屉，点一下就打开
- 记忆区：左边是活页、说明、资料的列表，右边看内容

#### 桌面版

- 是一个独立的窗口，不需要浏览器和黑色窗口
- 点 × 是藏到右下角托盘（时间旁边），工具继续运行；点托盘图标叫回来。设置 → 桌面版 里可以改成点 × 直接退出
- 右键托盘图标：截图识字（认出来的字直接复制好）、开机自动启动、退出
- 快捷键在哪都能按：Ctrl+Alt+B 叫出 / 藏起百宝匣，Ctrl+Alt+X 老板键（马上藏起来）。设置 → 桌面版 里可以改
- F5 刷新，Ctrl + 加号 / 减号 放大缩小，F12 开发者工具
- 数据就在"百宝匣.exe"旁边，整个文件夹拷走就是全部家当

#### 文件夹里都是什么

| 文件 | 作用 |
| --- | --- |
| 百宝匣.exe / 启动百宝匣.bat | 打开百宝匣 |
| tools.json | 工具区的所有工具 |
| 记忆区 | 所有说明（.md 文件） |
| 记忆区/资料 | 拖进来的 PDF、电子书、Office 文件 |
| 记忆区/图片 | 说明里的图片 |
| 图标 | 上传的抽屉图标图片 |
| 皮肤 | 自己装的皮肤 |
| 随身口袋 | 口袋里的文件 |
| 工具安装包 | 给工具准备的安装包（带走方式） |
| .末影箱 | 末影箱的连接信息和同步记录，不用动 |
| settings.json、layout.json、统计.json | 设置、栏目、使用统计，不用手动改 |
| 浏览器插件 | 网页剪藏插件，装到浏览器里用 |
| 恢复前的旧文件 | 恢复备份、装更新包之前，被换掉的旧文件存在这里 |
| server.js、public、lib、defaults | 百宝匣自己的程序，不用动 |

#### 更新百宝匣

小更新包（文件名像"Baibaoxia-Update-0.18.0.bbupdate"，一般只有几 MB）：

1. 把它拖进百宝匣窗口（或者右上角齿轮 →"更新百宝匣"→ 点"选文件"）
2. 会弹出"从 x 版更新到 y 版？"，上面写着这次改了什么，点"确定"
3. 桌面版：自动重新打开，就是新版了
4. 网页版：关掉黑色窗口（或在设置里点"关闭百宝匣"），重新双击"启动百宝匣.bat"，再按 Ctrl+F5 刷新页面

- 更新包只换百宝匣自己的程序文件，你的工具、说明、资料、皮肤、设置都不会动
- 被换掉的旧文件存在"恢复前的旧文件"里，出问题可以拷回去
- 更新包坏了、版本比现在还旧、或者里面有不该有的东西，都不会安装。只装作者发布的更新包
- 提示"换了桌面版的内核"或"请下载完整版"时：先从托盘彻底退出，再把完整版压缩包解压覆盖进去，数据不会被覆盖
- 提示"没有权限写入"：百宝匣放在了 C:\Program Files 这类系统文件夹里，把整个文件夹挪到比如 D:\百宝匣 再试

#### 关闭和开机自启

右上角齿轮里：

- 关闭百宝匣：如果有工具在运行，会问你要不要一起关掉。选"让它们继续运行"，开着的工具还能接着用
- 开机自动启动：开机后百宝匣在后台悄悄运行。桌面版待在托盘里；网页版用浏览器打开 http://127.0.0.1:3456 就行，建议收藏这个网址
- 网页版直接关掉黑色窗口也能关闭，但它开的工具会一起被关掉

### 二、工具区

#### 加一个工具

1. 工具区点最后一格虚线的"加一个工具"
2. 选它是什么：
    - 网址：直接粘贴网址
    - 文件夹：在文件资源管理器里打开它，点顶部地址栏，Ctrl+C 复制，粘贴进来
    - 程序：按住 Shift 右键程序 →"复制文件地址"，粘贴进来（.exe、.bat 都行）
    - 本地项目（比如从 GitHub 下载的小网站）：粘贴项目文件夹位置，点"自动识别"，启动命令和网址会自动填好，看一眼对不对
    - 组合技：一个按钮按顺序做好几件事（见下面）
3. 填名字、挑个图标，点"放进柜子"

勾上"同时在记忆区建一篇说明书"，会自动生成一篇说明，记着怎么手动启动，以后踩了坑往里面补。抽屉的 ⋯ 面板里会有"看说明书"按钮。

本地项目点一下会自动启动、等它准备好再打开网页；缺少零件（比如 node_modules）时会先自动安装。启动失败会告诉你原因，常见问题有修复按钮，"看运行记录"能看到具体报错。

#### 改工具、拿掉工具

点抽屉右上角的 ⋯：打开、停止（本地项目）、打开文件夹、看运行记录、修改这个工具、从柜子里拿掉。

#### 栏目和排序

- 新建：工具区左上角"＋ 新建栏目"，起个名字。栏目平时收起，点一下展开
- 放进栏目：按住抽屉拖到栏目上松手；或者修改工具时在"放进哪个栏目"里选
- 排序：按住抽屉拖到别的抽屉左边或右边；按住栏目的深色条可以上下拖动栏目
- 拖到收起的栏目上停一会儿，它会自动展开
- 改名、删除栏目：点栏目右边的 ⋯。删除栏目不会删里面的工具，它们会回到"未分类"
- 触屏电脑：用手指按住抽屉半秒，感觉它"浮起来"后就能拖

#### 图片图标

修改工具时，图标那里点"用图片"，选一张 png、jpg 等图片（比如网站的 logo），就会代替 emoji 显示在抽屉上。

#### 组合技

加工具时"这是什么"选组合技，用下面的按钮加步骤：

- 打开一个工具：从柜子里选。本地项目会自动等它准备好再做下一步
- 等几秒：比如等代理软件连上
- 打开网址

步骤可以用 ↑ ↓ 调顺序。点这个抽屉，步骤会从上往下依次做；哪一步失败就停下，告诉你是哪一步、为什么。

例子"开工模式"：打开代理软件（先把它加成"程序"类型的工具）→ 等 3 秒 → 打开某个本地项目 → 打开项目的说明网页。

#### 从 GitHub 收编项目

1. 加工具，选"本地项目"
2. 在"从 GitHub 收编"里贴项目网址，比如 https://github.com/作者名/项目名 ，点"下载"
3. 项目会下载到 `C:\Users\你的用户名\百宝匣项目\项目名`，启动命令、网址会自动填好
4. 看一眼没问题，点"放进柜子"

以后点这个抽屉的 ⋯ →"检查更新"，有新版本就点"更新到新版本"。更新只覆盖项目自带的文件，你自己的数据（比如 node_modules、data 文件夹）不会被删。

GitHub 在国内有时连不上，在设置 → 联网代理里填上代理软件的地址（比如 http://127.0.0.1:7890）就好。

#### 自带的工具

- 解除复制限制：一个书签工具。点抽屉看说明，把按钮拖到浏览器书签栏上；以后遇到不让复制、不让右键的网页，点一下书签就能复制了
- 截图识字（Windows）：点抽屉，屏幕变暗后框住要识别的文字，松手，几秒后识别出的文字已经复制好，直接 Ctrl+V。也可以在这个面板里 Ctrl+V 粘贴一张图片来识别。用的是 Windows 自带的识字功能，不用联网。提示"没装识字用的语言包"时：设置 → 时间和语言 → 语言和区域 → 中文（简体）旁边的 ⋯ → 语言选项 → 安装"光学字符识别"
- 百宝匣主页、记忆区文件夹：示例抽屉，不要可以拿掉

#### 工具体检

工具区右上角"体检"。

- 快速体检：看网址能不能打开、文件和文件夹还在不在，几秒钟
- 完整体检：本地项目会真的启动一次再关掉，久一点
- 有问题的抽屉左上角会出现一个 ! 号，鼠标放上去能看到原因；能自动修的会有修复按钮
- 百宝匣每周会自动做一次快速体检

#### 带走方式（工具在别的电脑上没有怎么办）

程序、文件夹、本地项目这类工具，换一台电脑就没有了。在工具的 ⋯ 面板最下面"带走方式"里提前准备好：

- 下载网址：官网下载页，或者绿色版的下载地址
- 安装包：放一个安装程序或者绿色版 zip，会加密存进末影箱，要用时才下载。最好放绿色版 zip，学校、网吧的电脑大多不让装软件
- 安装说明：在"修改这个工具"里给它挑一篇说明书，写清楚怎么装、要注意什么

在别的电脑上点这个工具时，会提示"这台电脑上没有它"，并给出几个办法：

- 从末影箱拿安装包：zip 会自动解压，认出程序在哪并打开，以后在这台电脑上点抽屉就直接打开；安装程序会直接运行
- 去下载页、看安装说明
- 从 GitHub 重新下载（从 GitHub 收编来的项目）
- 它在这台电脑的别的位置：告诉百宝匣它在哪，只对这台电脑有效，不会改到别的电脑

要在别的电脑上看到这些，末影箱要打开"工具和栏目"同步。

### 三、记忆区

#### 说明

说明就是记忆区里的 .md 文件（Markdown 格式），能在百宝匣里直接编辑。

- 新建：点"新建说明"，写标题
- 修改：打开一篇说明，点右上角"编辑"，改完点保存。标题改了文件名会跟着改
- 格式：第一行 `# 标题`，第二行 `标签: 词1, 词2`，然后 `## 速查` 写最关键的几步，速查会显示成黄色便签；后面用 `## 详细` 写完整内容
- 图片：截图直接 Ctrl+V 粘贴进编辑框，或者把图片拖进编辑框。图片存在"记忆区/图片"里，正文里写成 `![](图片地址)`
- .md 文件直接拖进窗口，就变成一篇说明
- 删除的说明会进回收站，还能找回来

#### 资料

拖进窗口的 PDF、电子书（.epub）、Word / Excel / PPT、文本文件都收进"资料"。

- 鼠标移到资料文件上，右边会出现"改名""删除"等按钮
- 百宝匣会在后台把里面的文字读出来，列表里显示"正在读取文字"，读完就能搜到。扫描出来的图片版 PDF 里没有文字，搜不到
- PDF：点一下在新窗口打开
- Word / Excel / PPT：在百宝匣里就能看。Word 的标题、表格、图片都在，Excel 按表格显示，PPT 一页一页显示文字。文档上方有"用系统软件打开""变成可编辑的说明""AI 提炼"
- 老的 .doc / .xls / .ppt 能收进来，但看不了内容也搜不到：用 Word / Excel 打开，另存为新格式再拖进来
- Windows 上，拖进来的图片会自动截图识字，图片里的字以后也能搜到

#### PDF 转成说明

PDF 只能看、能搜，不能改。想把一篇 PDF 文章变成能修改的说明：在资料里它那一行点"转成说明"，起个名字点"开始转"。

- 文字会整理成段落；字号明显大的短行会变成小标题，"1. 2."这类编号保留成列表
- 图片会从页面上裁下来，放在原来的位置
- 扫描版的 PDF（整页都是图片、没有文字）每页存成一张图
- 分两栏、表格很多的 PDF 排版可能会乱，转好以后点"编辑"自己调一下
- 原来的 PDF 还留在资料里，不需要了可以删掉；PDF 在哪张活页里，新说明也放进同一张

#### 电子书

- 在资料里点 .epub 文件就在百宝匣里打开。左边是目录；←→ 键或下面的按钮翻章；A− A+ 调字号；会记住读到哪，下次打开接着读
- 用鼠标选中一段文字，上面会弹出"划线 / 写笔记 / 复制"；划过的地方是黄色，点它可以改笔记或删掉
- 顶部"笔记"按钮：看这本书所有的书签和笔记，点一条就跳过去；"在这里加书签"；"导出成一篇说明"会生成《书名》读书笔记，每章有个"回到这一章"的链接

#### 搜索

- 按 `/` 或点顶上的搜索框打字，工具、说明、资料一起搜；回车直接打开第一个结果
- 资料分成两栏："文件名里有"和"文件内容里有"。内容命中会显示在第几页（电子书是哪一章）和附近的句子，点一下：PDF 直接跳到那一页；电子书、Word 等在百宝匣里打开，跳到那个地方，搜的词标成黄色
- 活页里的东西照样能搜到

#### 活页（分门别类收起来）

记忆区最上面是一叠带彩色标签的活页，像夹在夹子里的分隔页。没放进活页的东西照常在下面的列表里。

- 新建：点"＋ 新活页"，起个名字。新的排在最前面，每排最多 5 张
- 打开 / 合上：点一个标签，那一张就展开，下面是它装的东西（多了会翻页）；再点一下合上
- 放东西进去：
    - 把下面列表里的说明或资料拖到标签上，松手就放进去
    - 右键任何一件东西 →"放进活页"，挑一张；也能"移出活页"或者"新活页并放进去"
    - 看说明、看文档时，标题下面的"在活页"可以直接改
    - 某张活页展开着的时候，新建的说明、从电脑拖进来的文件都直接放进这一张
    - 从电脑拖文件进窗口时，屏幕下方会冒出一排活页，拖到哪张上就放进哪张，也可以选"先不放"
    - 有一张叫"剪藏"的活页的话，剪藏的文章会自动放进去
- 改名、换颜色、删掉：右键标签，或者点展开那张右上角的 ⋯。删掉活页不会删里面的东西
- 换位置：按住一个标签拖到另一个标签上，就排到它前面；也可以右键 →"往前挪 / 往后挪"
- 钉住：右键标签 →"钉住"，它会一直排在最前面
- 在活页里置顶：右键活页里的某件东西 →"在活页里置顶"
- 快捷键：Alt+1 打开第 1 张……一直到 Alt+9
- 活页太多：最多显示三排，放不下的收进最后一个"+几"标签里，点它能看到全部，还能打字找
- 档案盒：暂时不用的活页，右键 →"放进档案盒"，标签就收起来了。点"全部活页"，在最下面的档案盒里点"拿出来"就回来了
- 导出 / 导入：右键标签 →"导出"，整张活页（说明、资料、图片）存成一个 .bbpage 文件，可以备份或者发给别人。把 .bbpage 拖进窗口就导入成一张新活页，重名的会自动改名，不会覆盖你的东西

#### 网页剪藏（浏览器插件）

装一次（Chrome 或 Edge 都行）：

1. 浏览器地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`），回车
2. 打开右上角（Edge 在左下角）的"开发者模式"
3. 点"加载已解压的扩展程序"，选百宝匣文件夹里的"浏览器插件"文件夹
4. 浏览器右上角的拼图图标里，把"百宝匣剪藏"固定出来

- 存一段：在网页上选中一段文字，选区右下角会冒出一个小图标，点一下就存好了。同一个网页存的几段会放进同一篇"《标题》（摘录）"里。不想在某个网站上看到小图标，点插件图标，勾上"在这个网站上不显示"
- 存整篇：点插件图标 →"存整篇文章"，或者在网页上右键 →"存进百宝匣"
- 文章存进记忆区左边单独的"剪藏"栏目（平时收起，点一下展开），图片下载到本地，最上面写着原网址。想把某篇剪藏挪到普通说明里，编辑它，把标签里的"剪藏"删掉
- 百宝匣要开着才能剪藏
- 插件更新以后：在 `chrome://extensions` 里"百宝匣剪藏"上点刷新按钮 ⟳，已经打开的网页也刷新一下

#### 回收站

记忆区左下角的"回收站"。删掉的说明和资料都在里面，可以一个个恢复，也可以彻底删除或清空。删不掉时点"打开回收站文件夹"手动删。

#### 使用统计

记忆区的"统计"按钮（工具区右上角也有）：

- 一共多少篇说明、多少份资料，最近 30 天新写、修改、剪藏了几篇
- 好久没看的说明：三个月没打开过的，翻一翻，免得要用时忘了还有它
- 在读的书、最常看的说明、最常翻的资料、常搜的词
- 搜了但没找到的词：说明你需要写一篇了，点一下直接新建
- 工具区：最常用的工具、两个月没用的工具

数据只存在本机的 统计.json 里。

### 四、AI 管家

先在右上角齿轮 → AI 里设置：点"DeepSeek"或"通义千问"会自动填好地址和模型，再填上你在那家网站申请的密钥，点"测试一下"。AI 要联网、按用量花钱（一般很便宜），用到的内容会发给你选的那家 AI 服务。

#### 问问

右上角"问问"。她会自己翻你的说明和资料，查完再回答，回答后面标出处，点出处能直接打开。可以直接吩咐她做事：

- "帮我看看 10 月 20 日存的资料主要讲了什么"：按日期找出来，读完再总结
- "我最近剪藏了哪些文章？""哪些说明好久没看了？""我在读哪些书？"
- "把这篇 PDF 的第 3 章总结一下"
- "打开记账本"：直接帮你打开工具
- "把刚才说的整理成一篇说明，放进学习活页"：新建说明、放进活页（活页不存在会自动新建）
- 她不会删除任何东西

问问面板顶上的"自由回答"开关：不勾时是"资料优先"，回答简短、尽量按你的资料说；勾上以后会用 AI 自己的知识完整、详细地回答，你的资料只当参考。设置 → AI 里可以设成默认打开。

#### 管家的名字和性格

右上角齿轮 → 管家，起个名字，写下她的性格、说话方式、口头禅，AI 会照着演。回答时她的表情会跟着变（思考、找到了、开心、犯困……）；皮肤带看板娘的话，看板娘也会跟着换动作。

#### AI 提炼和 AI 整理

- AI 提炼：资料上鼠标移过去点"AI 提炼"，把一本手册提炼成一张速查卡，满意就"存成新说明"
- AI 整理：打开一篇自己写的说明，点"AI 整理"，把乱的笔记理成清楚的步骤；可以替换原文，也可以另存

### 五、随身口袋和末影箱

#### 随身口袋

右上角"口袋"。一个放随手文件的地方：作业、要打印的东西、从别的电脑带回来的文件。

- 放进去：把文件拖进口袋面板；或者在任何地方拖文件进窗口，松手前放到底部的"放进随身口袋"上
- 拿出来：把文件从口袋列表拖到桌面、文件夹、QQ / 微信聊天窗口、网页的上传框（网页版要用 Chrome 或 Edge）。双击或点"打开"直接打开
- 删掉的先进口袋的回收站，可以放回来

#### 末影箱是什么

末影箱让口袋（还可以加上记忆区、工具、皮肤和 AI 设置）跟着你走：东西加密以后存进你自己的 GitHub 私有仓库，在别的电脑上打开百宝匣、连上同一个末影箱，就能拿到同样的东西。加密在你电脑上完成，GitHub 上只能看到乱码，百宝匣没有服务器。

#### 第一次设置（大约 5 分钟）

1. 在 GitHub 上新建一个私有仓库：打开 https://github.com/new ，名字填比如 my-box，一定选 Private
2. 生成令牌：打开 https://github.com/settings/personal-access-tokens/new ，Repository access 选 Only select repositories 并勾上这个仓库，Permissions 里把 Contents 设成 Read and write，点 Generate token，马上把 github_pat_ 开头的那串字复制下来
3. 百宝匣里：口袋 →"连接末影箱"，填仓库（你的用户名/my-box）和令牌，设一个箱子密码（至少 6 位，忘了谁都打不开，一定记牢），给这台电脑起个名字
4. 勾上还要同步什么（见下面），点"连接"

口袋按钮上的小点：绿色是已连上，黄色闪是正在同步，红色是出错了（打开口袋能看到原因）。

#### 同步什么

连接时可以勾选，以后在 口袋 → 末影箱设置 → 同步什么 里也能改。关掉某一项只是不再同步，两边的东西都不会删。

- 随身口袋：一定同步
- 记忆区：说明、资料、图片、活页
- 工具和栏目：连同工具的图标和安装包
- 外观和 AI：皮肤（包括自己装的皮肤和看板娘）、AI 的接口地址、模型和密钥、管家的名字和性格。代理、备份位置这些每台电脑不一样的不同步

同步怎么进行：

- 有变化几秒后自动同步，平时每分钟检查一次；口袋面板里的"同步"按钮可以马上同步；退出百宝匣前会把没传完的再传一下
- 20 MB 以下的文件自动下载到每台电脑；更大的在别的电脑上显示为"在云端"或"☁ 在末影箱里"，要用时点"拿下来"
- 两台电脑同时改了同一个文件：两份都留，另一份改名为"文件名（来自 那台电脑）"
- 两台电脑都改了工具：按每个工具合并；同一个工具两边都改了，以后同步的那台为准
- 一台电脑上删掉的，其他电脑上也删掉（先放进各自的回收站）
- 新电脑第一次连上时，自带的示例说明和示例工具会让位给末影箱里的版本

#### 连接码

令牌又长、关掉 GitHub 页面就找不回来。自己电脑上：口袋 → 末影箱设置 → 连接码，输箱子密码点"生成"，会自动复制好，存到手机备忘录或者发到微信"文件传输助手"。到了别的电脑上，选"我有连接码"，粘贴连接码、输箱子密码就能连上。

连接码是用箱子密码加密的，别人拿到了没有密码也用不了。箱子密码别和连接码存在一起。

#### 在别人的电脑上用：临时模式

1. 出门前：要带的文件放进口袋，看到 ✓ 再走；手机里存好连接码
2. 在那台电脑上下载桌面版 zip，解压到桌面或 D 盘，双击"百宝匣.exe"（不需要管理员权限）
3. 问"这是你自己的电脑吗？"时选"临时用一下"，窗口会闪一下重新打开
4. 自动弹出末影箱连接页面：用连接码连上，口袋、说明、工具就都过来了
5. 用完点 × 关掉：临时模式下点 × 就是退出，这台电脑上的数据、令牌、密码、浏览记录、解压出来的工具全部删掉。在那边放进口袋的文件会先传到末影箱

- 朋友、同学自己在用的百宝匣，不要直接连你的末影箱，不然那台电脑原来的说明和工具会和你的合在一起
- 解压出来的程序文件夹可以顺手删掉，里面没有你的数据

#### 末影箱网页版

没装百宝匣、或者不让运行 exe 的电脑：浏览器打开 https://mengyiheqiao.github.io/baibaoxia/box/ ，贴连接码、输箱子密码。打不开的话，到 Releases 页面下载 Baibaoxia-Box-Web.html，双击打开也一样。

- 随身口袋：下载、上传、删除，改动会同步到所有连着的电脑
- 记忆区：看说明的内容、下载资料
- 工具：网址类直接打开，有安装包的可以下载

加密解密都在网页里完成，关掉网页什么都不留。

#### 常见问题

- 连接时说"连接超时"：这台电脑连不上 GitHub。自己电脑上可以在设置 → 联网代理里填代理地址；学校电脑上可以换个时间，或者用手机热点
- 说"令牌没有这个仓库的权限"：生成令牌时没勾上这个仓库，或者 Contents 不是 Read and write，重新生成一个
- 说"箱子密码不对"：这个仓库之前已经设过密码了，要用第一次设的那个
- 令牌过期了（口袋上出现红点）：在 GitHub 的令牌页面点 Regenerate token 换一串新的，然后 口袋 → 末影箱设置 → 断开，用新令牌再连一次（仓库和密码不变，东西不会丢），再重新生成连接码
- 令牌存在哪：这台电脑百宝匣文件夹里的 .末影箱 文件夹，不会上传；存的是令牌和由箱子密码算出来的加密钥匙，不存密码本身

更详细的教程见 GitHub 上的 docs/末影箱.md。

### 六、皮肤和看板娘

右上角齿轮 → 皮肤，点一下就换，功能都不变。自带四套：

- 原皮：深色木柜子 + 铜拉环
- 极简：白底细线，左边是菜单，工具排成清单；电脑开了深色模式时它也会变深色
- 动漫：粉色波点、贴纸卡片，工具区右下角有看板娘"匣宝"（窗口够宽时才出来）
- 星空：深蓝夜空，星星绕着北极星缓缓旋转，银河和星云在呼吸，偶尔划过流星。工具是悬浮的星辰卡：正在运行的有一颗小卫星环绕；常用的工具更亮，最常用的带一圈光晕。电脑开了"减少动画"时，星空会停下来

看板娘：有的皮肤带一个看板娘，站在工具区右下角，会呼吸、眨眼，跟着"问问"的回答换动作，点她就能聊天，很久不操作会犯困。看板娘可以是一套立绘，也可以是 Live2D 模型：Live2D 的头和眼睛会跟着鼠标转，说话时会动嘴。第一次显示 Live2D 看板娘时，百宝匣会从 Live2D 官网下载它要用的运行库（只下载一次）。不想要可以在 设置 → 皮肤 里关掉"显示看板娘"。

装别人做的皮肤：皮肤是一个 .bbskin 文件，直接拖进窗口就装好、自动换上；也可以在设置 → 皮肤里点"选文件"。装过的皮肤鼠标移上去能"删掉"。"皮肤示例"文件夹里有一个护眼.bbskin 可以试，旁边的《皮肤制作说明》讲了怎么自己做（包括给皮肤加看板娘）。

皮肤只能改样子，不能带程序，比较安全。换了皮肤以后界面乱了、找不到按钮，按 Ctrl+Alt+0 马上换回原皮；或者打开 http://127.0.0.1:3456/?skin=off 临时用原皮。

### 七、数据安全

#### 自动备份

右上角齿轮 → 自动备份，填一个网盘会自动同步的文件夹（OneDrive、百度网盘同步空间等）。百宝匣会在里面建一个"百宝匣备份"文件夹，每 30 分钟检查一次，只复制改过的文件，不会删除备份里的任何东西。

备份的内容：记忆区、随身口袋、工具、栏目、图标、设置。

从备份恢复（换了电脑或误删了文件时）：右上角齿轮 → 自动备份 → 从备份恢复。

- 备份里有、这台电脑上没有的文件会直接拷回来
- 两边都有但内容不一样的，会问你要不要用备份覆盖；覆盖前会把电脑上现在的版本存到"恢复前的旧文件"，不会丢
- 新电脑上要先装好百宝匣，在设置里填上同一个备份位置，再点"从备份恢复"

自动备份和末影箱可以一起用：备份是复制一份到网盘文件夹，末影箱是在几台电脑之间同步。

#### 隐私

- 所有东西都存在你自己的电脑上，百宝匣没有服务器，也不收集任何信息
- 百宝匣只在本机（127.0.0.1）上运行，局域网里的其他电脑访问不到
- 只有这些情况会联网：点开网址类工具；从 GitHub 下载或更新项目；剪藏网页图片；用 AI；连着末影箱时同步（加密后上传到你自己的 GitHub 私有仓库）

#### 联网代理

设置 → 联网代理：从 GitHub 下载项目、剪藏国外网页的图片、工具体检、末影箱同步时用。开着 Clash 之类的代理软件就填它的地址（比如 http://127.0.0.1:7890）。用国外的 AI 服务时，在 AI 设置里勾上"AI 也走上面的代理"。

### 九、高级：直接改 tools.json

平时不用看这一节。所有工具其实都存在 tools.json 里，页面上填表就是在改它。每次修改前会自动备份成 tools.json.bak，改坏了可以把 .bak 改回原名。

整个文件是一对方括号 `[ ]`，里面每个工具是一对花括号 `{ }`，工具之间用英文逗号隔开。

服务型（要先启动、再打开网页的项目）：

```
{
  "名字": "记账本",
  "图标": "📒",
  "类型": "服务",
  "一句话": "本地跑的记账小网站",
  "文件夹": "C:/Users/你的用户名/记账本",
  "启动命令": "node server.js",
  "网址": "http://127.0.0.1:3210",
  "就绪检查": "http://127.0.0.1:3210/healthz",
  "缺少时先运行": { "缺少": "node_modules", "运行": "npm install" },
  "说明书": "记账本"
}
```

网址型：

```
{ "名字": "GitHub", "图标": "🐙", "类型": "网址", "网址": "https://github.com" }
```

文件夹型：

```
{ "名字": "下载", "图标": "📥", "类型": "文件夹", "文件夹": "C:/Users/你的用户名/Downloads" }
```

程序型（打开电脑上的某个软件或 .bat）：

```
{ "名字": "记事本", "图标": "📝", "类型": "程序", "程序": "C:/Windows/notepad.exe" }
```

写的时候注意：

- 路径用正斜杠 `/`，例如 `C:/Users/...`。如果要用反斜杠，必须写两个 `\\`
- 所有引号、冒号、逗号都要用英文的
- 最后一个工具后面不要加逗号
- 写错了不用怕，刷新页面时百宝匣会提示大概在第几行

| 名字 | 意思 | 必填 |
| --- | --- | --- |
| 名字 | 抽屉上写的字 | 是 |
| 图标 | 抽屉上的图案，可以用任意 emoji | 否 |
| 类型 | 服务 / 网址 / 文件夹 / 程序 / 书签工具 / 组合 | 是 |
| 一句话 | 鼠标悬停时的说明 | 否 |
| 文件夹 | 项目所在位置 | 服务、文件夹必填 |
| 启动命令 | 在项目文件夹里运行的命令 | 服务必填 |
| 网址 | 启动好后打开的网页 | 服务、网址必填 |
| 就绪检查 | 能打开就说明启动好了的网址，不填就用"网址" | 否 |
| 缺少时先运行 | 缺少某个文件夹时，先运行一条安装命令 | 否 |
| 最多等待秒数 | 启动最多等多久，默认 40 | 否 |
| 说明书 | 记忆区里对应说明的标题 | 否 |
| 栏目 | 放在哪个栏目 | 否 |
| 带走 | 带走方式：下载网址和安装包，在页面上填 | 否 |
