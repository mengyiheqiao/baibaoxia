百宝匣桌面版 —— 先看我
==========================

【怎么打开】
1. 把整个"百宝匣"文件夹放到一个普通的地方，比如 D:\百宝匣 或"文档"里。
   不要放进 C:\Program Files（那里没法保存数据）。
2. 双击"百宝匣.exe"。
3. 第一次打开时，Windows 可能弹出蓝色的"Windows 已保护你的电脑"：
   点"更多信息" → "仍要运行"。（因为这个软件是自己做的，没有花钱买微软的签名。）
4. 第一次打开会问要不要把网页版的数据搬过来：
   点"搬过来"，选以前那个百宝匣文件夹（里面有"启动百宝匣.bat"和"记忆区"的那个）。
   只是复制一份，原来的不会动。

想在桌面上放一个图标：右键"百宝匣.exe" → 显示更多选项 → 发送到 → 桌面快捷方式。

【平时怎么用】
- 点窗口右上角的 ×：百宝匣藏到屏幕右下角的托盘里（时间旁边，可能要点一下 ^ 才看到），工具继续运行。
- 点托盘图标：叫出 / 藏起百宝匣。右键托盘图标：截图识字、开机自动启动、退出。
- 快捷键（在哪都能按）：
    Ctrl + Alt + B   叫出 / 藏起百宝匣
    Ctrl + Alt + X   老板键：马上藏起来
  在 设置 → 桌面版 里可以改。
- 彻底退出：右键托盘图标 → 退出百宝匣，或者 设置 → 关闭百宝匣。
- 开机自动启动：设置里勾上，开机后它安静地待在托盘里。
- 界面乱了：按 F5 刷新；按 Ctrl+Alt+0 换回原皮；Ctrl + 加号 / 减号 可以放大缩小。

【数据放在哪】
就在"百宝匣.exe"旁边：记忆区、tools.json、settings.json 这些。
备份这个文件夹就等于备份了百宝匣（设置里的"自动备份"也会自动做）。

【以后更新】
小更新包（.bbupdate 文件）：直接拖进百宝匣窗口，点"确定"，会自动重新打开，数据不会动。
完整版压缩包：先彻底退出百宝匣（右键托盘图标 → 退出；还不行就在任务管理器里结束"百宝匣"），
再把压缩包里的东西解压覆盖到这个文件夹，你的数据不会被覆盖。
提示"目标文件夹访问被拒绝"：一般是百宝匣还没退干净，或者文件夹放在了 C:\Program Files 里，
挪到比如 D:\百宝匣 就好。

【浏览器插件】
"浏览器插件"文件夹就是网页剪藏插件，安装方法见百宝匣里的《百宝匣使用说明》。

【不想要了】
先在设置里取消"开机自动启动"，退出百宝匣，再删掉整个文件夹。
