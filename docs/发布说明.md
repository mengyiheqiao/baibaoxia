## 下载哪个？

| 文件 | 适合谁 |
| --- | --- |
| **百宝匣-桌面版-x.x.x.zip** | 大多数人选这个。Windows 10 / 11，解压后双击"百宝匣.exe"，不用装别的 |
| 百宝匣-网页版-x.x.x.zip | 已经装了 [Node.js](https://nodejs.org)，想在浏览器里用；也能在 macOS / Linux 上跑 |
| 百宝匣更新-x.x.x.bbupdate | 已经在用百宝匣（0.11.0 或更新）的人：拖进百宝匣窗口就能升级，数据不会动 |

第一次用请看 [README](https://github.com/mengyiheqiao/baibaoxia#readme)。

Windows 可能会提示"已保护你的电脑"（因为软件没有付费签名）：点"更多信息" → "仍要运行"。
