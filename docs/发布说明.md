## 0.17.0 新增：外观和 AI 也能同步

- 末影箱新增"外观和 AI"：皮肤、看板娘、AI 设置、管家跟着走，换台电脑界面和"问问"都和自己电脑上一样
- 在别人的电脑上连末影箱，请用临时模式；连接页面里加了提醒

## 0.16.0 新增：末影箱同步记忆区和工具、带走方式、网页版

- 末影箱可以同步记忆区（说明、资料、图片、活页）和工具、栏目，两台电脑都改了会按条目合并
- 带走方式：给工具放下载网址或绿色版 zip，换台电脑没有这个工具时，点一下就装好打开
- 末影箱网页版：下载 Baibaoxia-Box-Web.html，没装百宝匣的电脑用浏览器打开就能拿文件

## 0.15.0 新增：随身口袋 + 末影箱

- 右上角"口袋"：文件拖进去、拖出来
- 末影箱：口袋里的东西加密后存进你自己的 GitHub 私有仓库，换台电脑也能拿到（[教程](https://github.com/mengyiheqiao/baibaoxia/blob/main/docs/%E6%9C%AB%E5%BD%B1%E7%AE%B1.md)）
- 临时模式：在学校、网吧的电脑上用，关掉就删干净

## 下载哪个？

| 文件 | 适合谁 |
| --- | --- |
| **Baibaoxia-Desktop-x.x.x.zip** | 大多数人选这个。Windows 10 / 11，解压后双击"百宝匣.exe"，不用装别的 |
| Baibaoxia-Web-x.x.x.zip | 已经装了 [Node.js](https://nodejs.org)，想在浏览器里用；也能在 macOS / Linux 上跑 |
| Baibaoxia-Update-x.x.x.bbupdate | 已经在用百宝匣（0.11.0 或更新）的人：拖进百宝匣窗口就能升级，数据不会动 |

第一次用请看 [README](https://github.com/mengyiheqiao/baibaoxia#readme)。

Windows 可能会提示"已保护你的电脑"（因为软件没有付费签名）：点"更多信息" → "仍要运行"。
