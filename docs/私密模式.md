# 私密模式

百宝匣里有一个单独的私密区。它有自己的工具、栏目、说明、资料、活页、回收站和皮肤，和普通区完全分开。

普通区的页面、设置和使用说明里都不会出现它，所以这份说明单独放在这里。

## 怎么进去

1. 打开百宝匣，按 **Ctrl+Alt+H**
2. 第一次会让你设一个密码（至少 4 位），设好就直接进去了
3. 以后每次按 Ctrl+Alt+H，输入密码就能进去

进去以后左上角的"百宝匣"会变成"私密区"。

## 怎么出来

- 再按一次 **Ctrl+Alt+H**，或者点右上角"锁上离开"
- 30 分钟不操作会自动锁上
- 桌面版按老板键（默认 **Ctrl+Alt+X**）：窗口马上藏起来，私密区同时锁上，下次打开看到的是普通区

桌面版里，私密区的快捷键在哪个软件里都能按。快捷键可以在私密区的设置里改，普通区的设置里看不到这一项。

## 在私密区里能做什么

- 加工具、写说明、拖进资料，这些都只存在私密区，普通区里搜不到
- 设置里有"把普通区的工具搬进来"
- 修改私密区里的工具时，取消"放在私密区"，它就搬回普通区
- 可以单独选一套皮肤，和普通区互不影响
- 选"星空"皮肤的话，私密区会变成深空：一个吸积盘不停旋转的黑洞，星屑被卷进去，工具也被它的引力轻轻拽着（鼠标移上去就停住）
- 私密区里也能用"问问"，管家可以单独设一套名字和性格（私密区设置 → 这边的管家），和普通区的互不影响
- 默认情况下，管家看不到私密区的任何资料，私密区的内容不会发给 AI；在私密区设置里勾上"允许管家看私密区的资料"后，问问时用到的私密区内容才会发给你设置的 AI 服务

## 同步到末影箱

连上末影箱以后（普通区的"口袋" → 连接末影箱），可以把这边也加密存进末影箱，换一台电脑也能进到同样的私密区。

1. 进私密区，右上角齿轮 → 末影箱
2. 勾上"同步私密区"，点保存

会同步的：这边的说明、资料、图片、活页、工具、栏目、皮肤、这边的管家，还有私密区的密码。

- 这个开关存在末影箱里，所有连着同一个末影箱的电脑都会照着做，包括临时模式的电脑（关掉百宝匣时会和别的东西一起删干净）
- 在另一台电脑上连好末影箱，等它同步一会儿，按 Ctrl+Alt+H，输这边的密码就能进来
- 如果某台电脑的私密区已经有自己的密码，而且和末影箱里的不一样（比如是别人的电脑），百宝匣不会碰它，也不会把它传上来；私密区设置里会提示
- 普通区的页面、口袋面板、同步进度里都不会出现这边的文件名
- 关掉：去掉勾点保存，只是以后不再同步；点"从末影箱里删掉这边的东西"会把云端的删掉，每台电脑上已经有的不动
- 在这边改了密码，其他电脑同步以后也会换成新密码

末影箱里的东西是用箱子密码加密的，私密区密码只用来挡住界面。

## 文件存在哪

- 网页版：百宝匣文件夹里的 `私密区` 文件夹
- 桌面版：`百宝匣.exe` 旁边的 `私密区` 文件夹
- 在 Windows 上，这个文件夹会被设成隐藏
- 自动备份也会把它一起备份

## 要知道的局限

- **密码只用来挡住百宝匣的界面和接口，文件本身没有加密。** 别人能直接打开你电脑上的文件夹的话，还是看得到里面的东西。真正要保密的文件，请再用 BitLocker、VeraCrypt 或者带密码的压缩包加一层。
- 密码不是明文保存的，`settings.json` 里只存了加盐后的 scrypt 哈希。

## 忘了密码

1. 彻底关掉百宝匣（桌面版：右键托盘图标 → 退出）
2. 用记事本打开 `settings.json`（网页版在百宝匣文件夹里，桌面版在 `百宝匣.exe` 旁边）
3. 删掉 `"私密密码": { ... }` 这一整段，注意别留下多余的逗号
4. 保存，重新打开百宝匣，按 Ctrl+Alt+H 重新设密码

私密区里原来的东西都还在。
