# 随身口袋和末影箱

随身口袋是百宝匣里一个放随手文件的地方：作业、要打印的东西、从别的电脑带回来的文件。

末影箱让口袋跟着你走。在自己电脑上放进口袋的文件，到了学校机房、公司、网吧的电脑上打开百宝匣，连上同一个末影箱就能拿到；在那边放进去的，回家也会出现在自己电脑上。

东西存在你自己的 GitHub 私有仓库里，上传前先用你的箱子密码加密，GitHub 上只能看到一堆乱码。百宝匣没有服务器，不经过任何第三方。

## 随身口袋怎么用

- 打开：右上角"口袋"
- 放进去：把文件拖进口袋面板；或者在任何地方拖文件进窗口，松手前放到底部的"放进随身口袋"上
- 拿出来：把文件从口袋列表里拖到桌面、文件夹、QQ / 微信聊天窗口、网页的上传框里（桌面版拖出来的就是文件本身；网页版需要用 Chrome 或 Edge）。双击文件或点"打开"直接打开
- 删掉的文件先进口袋的回收站，可以放回来

文件存在百宝匣文件夹里的"随身口袋"文件夹，自动备份也会把它一起备份。

## 第一次设置末影箱（大约 5 分钟）

需要一个 GitHub 账号。没有的话先到 https://github.com/signup 注册一个，免费。

### 1. 建一个私有仓库

1. 打开 https://github.com/new
2. Repository name 随便填，比如 `my-box`
3. 选 **Private**（一定要选私有）
4. 其他都不用动，点最下面的 Create repository

### 2. 生成一个令牌

令牌相当于给百宝匣的一把钥匙，只能开这一个仓库。

1. 打开 https://github.com/settings/personal-access-tokens/new （GitHub 右上角头像 → Settings → 左边最下面 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token）
2. Token name 随便填，比如 `百宝匣`
3. Expiration（有效期）：可以选 1 年，或者 No expiration（不过期）。过期了重新生成一个填进去就行
4. Repository access 选 **Only select repositories**，下拉框里勾上刚才建的 `my-box`
5. Permissions → Repository permissions 里找到 **Contents**，改成 **Read and write**（Metadata 会自动变成 Read-only，不用管）
6. 点最下面的 Generate token，把出现的那串 `github_pat_` 开头的字复制下来。这个页面关掉以后就再也看不到了，先存好

### 3. 在百宝匣里连上

1. 右上角"口袋" → "连接末影箱"
2. 仓库填 `你的用户名/my-box`，令牌粘贴进去
3. 设一个箱子密码（至少 6 位）。以后每台电脑都用这个密码
4. "这台电脑叫"填个好认的名字，比如"宿舍电脑"。别的电脑上能看到文件是从哪台传上来的
5. 点"连接"

连上以后，口袋里已有的文件会自动传上去。

箱子密码一定记牢。忘了的话，末影箱里的东西谁都打不开，包括你自己。

## 在别的电脑上用

### 学校、网吧这种别人的电脑：临时模式

1. 在那台电脑上下载桌面版 `Baibaoxia-Desktop-x.x.x.zip`，解压，双击"百宝匣.exe"
2. 第一次打开会问"这是你自己的电脑吗？"，选"临时用一下"
3. 百宝匣会直接打开末影箱的连接页面：填仓库、令牌、箱子密码，或者用下面说的连接码
4. 口袋里的东西就下来了。用完直接关掉百宝匣窗口

临时模式下，百宝匣的所有数据（包括令牌和密码、浏览记录）都放在系统的临时文件夹里，关掉百宝匣时整个删掉，不会留在那台电脑上。关之前在那边放进口袋的文件会先传到末影箱（最多等 20 秒）。

用完后解压出来的百宝匣程序文件夹还在，可以顺手删掉，里面没有你的数据。

### 连接码：不用每次都去翻令牌

令牌又长又难记。可以在自己电脑上生成一个"连接码"：

1. 自己电脑上：口袋 → 末影箱设置 → 输入箱子密码 → 生成。连接码会自动复制好
2. 存到手机备忘录里，或者发到微信"文件传输助手"
3. 在别的电脑上连接时，选"我有连接码"，粘贴连接码、输箱子密码就行

连接码是用箱子密码加密过的，别人拿到了没有密码也用不了。

### 另一台自己的电脑

正常装好百宝匣（第一次打开选"我自己的电脑"），然后照"在百宝匣里连上"做一遍，用同一个仓库和同一个箱子密码。之后两台电脑的口袋会自动保持一样。

## 同步是怎么进行的

- 口袋里有变化，几秒后自动同步；平时每分钟检查一次。口袋面板里的"同步"按钮可以马上同步
- 20 MB 以下的文件会自动下载到每台电脑；更大的文件在别的电脑上显示为"在云端"，要用时点"拿下来"，省流量也省时间
- 单个文件最好不要超过 1 GB。大文件会切成 25 MB 一块上传
- 两台电脑同时改了同一个文件：两份都留，另一台电脑的那份会改名成"文件名（来自 那台电脑）"
- 在一台电脑上删掉的文件，其他电脑上也会删掉（先放进各自的回收站）
- 被别的电脑上的新版本换掉的旧文件，也会先放进回收站
- 退出百宝匣时，没传完的会再等最多 20 秒

右上角"口袋"按钮上的小点：绿色是已连上，黄色闪是正在同步，红色是出错了（打开口袋能看到原因）。

## 常见问题

**连接时说"连接超时"**：GitHub 在国内有时连不上。在设置 → 联网代理里填上代理地址（末影箱会走这个代理）。学校电脑上没有代理的话，可能只能换个时间或者换个网络试试。

**说"令牌没有这个仓库的权限"**：生成令牌时没勾上这个仓库，或者 Contents 不是 Read and write。重新生成一个。

**说"箱子密码不对"**：这个仓库之前已经设过密码了，要用第一次设的那个。

**令牌过期了**：口袋上会出现红点，提示令牌不对。重新生成一个令牌，口袋 → 末影箱设置 → 断开，再用新令牌连一次（仓库和密码不变，文件不会丢）。连接码里带着旧令牌，记得重新生成一个。

**仓库会不会越来越大**：删掉的文件不会再出现在末影箱里，但 GitHub 会保留历史记录，仓库会慢慢变大。GitHub 建议仓库不超过几个 GB。真的太大了：在一台电脑上断开，到 GitHub 上把仓库删掉、重新建一个同名的，再连接一次，口袋里的文件会重新传上去（相当于清空历史）。

**令牌存在哪**：自己的电脑上，存在百宝匣文件夹里的 `.末影箱` 文件夹（Windows 上是隐藏的），不会上传。存的是令牌和由箱子密码算出来的加密钥匙，不存密码本身。临时模式下关掉百宝匣就删掉了。

**私密区的东西会同步吗**：不会。末影箱只同步随身口袋。

**以后能同步记忆区和工具吗**：在计划里。

## GitHub 上能看到什么

仓库里只有这几样：

| 文件 | 是什么 |
| --- | --- |
| box-salt.json | 加密用的参数（不是秘密），和一段用来核对密码的密文 |
| box.json | 加密后的文件清单 |
| o/ 文件夹 | 加密后的文件内容 |

文件名和内容都加密了（AES-256-GCM，密钥由箱子密码经 scrypt 算出）。别人能看出的只有：大概有几个文件、每个加密块多大。请不要手动修改这个仓库里的东西。
